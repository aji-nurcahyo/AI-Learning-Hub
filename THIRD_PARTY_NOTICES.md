# Atribusi software

AI Learning Hub dikembangkan oleh Aji Pamungkas Tri Nurcahyo untuk Institut Teknologi Sumatera. Identitas ini tidak berarti seluruh kode asal ditulis oleh pengembang platform.

Fondasi langsung: proyek lokal Python Learning Hub, commit 7c612bedbd2da4e0d04f127d01b9a0435c20cda6; digunakan atas instruksi pemilik. File referensi tetap read-only. Komponen disalin: src/ui/*, src/theme/styles.css, src/deck-shell/*, konfigurasi TypeScript/ESLint dan manifest dependensi. Adaptasi didokumentasikan pada docs/DEVELOPMENT_PLAN.md.

Referensi tersebut mengatribusikan fondasi pada Pengkom Informatika ITERA: https://github.com/informatika-itera/pengkom, commit 30ce99f8a4a4bed7e9dc7d801a0030da949df3ab. src/ui/highlight.ts dan src/ui/Math.tsx berasal dari sana. Pemberitahuan MIT upstream dengan copyright Hakim El Hattab dan kontributor Reveal.js dipertahankan byte-for-byte pada LICENSE.upstream. Jangan menafsirkan satu notice tersebut sebagai pemberian lisensi terhadap semua materi edukasi proyek asal.

Materi kursus, slide dan kode contoh lama tidak disalin. Referensi akademik ditautkan untuk pengembangan mandiri; tidak direproduksi.

Lisensi package dan font terpasang tercatat dalam docs/DEPENDENCY_LICENSES.json. Lisensi dataset/model belum berlaku karena tidak ada yang didistribusikan. Lihat docs/LICENSE_REGISTER.md.
