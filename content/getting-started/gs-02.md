# GS-02: Python Installation & Verification

Modul ini menjelaskan tata cara instalasi Python versi stabil yang kompatibel dengan ekosistem AI modern, langkah verifikasi instalasi, dan cara mendeteksi konflik lingkungan.

## Tujuan

Setelah menyelesaikan modul ini, Anda diharapkan mampu:
1. Memasang Python versi stabil yang didukung secara luas oleh pustaka AI (disarankan Python 3.11 atau 3.12).
2. Memverifikasi ketersediaan executable Python dan package manager `pip` di sistem operasi Anda.
3. Mengidentifikasi lokasi executable interpreter untuk memastikan tidak terjadi benturan dengan instalasi lama.

## Prasyarat

- Hak akses administrator pada komputer Anda untuk memasang software.
- Terminal bawaan: PowerShell / Command Prompt (Windows), Terminal (macOS / Linux).

## Pemilihan Versi Python

Dalam pengembangan AI dan data science:
- **Jangan selalu memilih versi Python yang paling baru dirilis (bleeding edge)**: Library komputasi numerik intensif seperti PyTorch, SciPy, dan TensorFlow membutuhkan kompilasi binary C/C++ (*pre-built wheels*). Rilis versi Python paling baru (misalnya beberapa minggu pertama setelah rilis mayor) sering kali belum memiliki pre-built wheels siap pakai.
- **Versi yang Sangat Direkomendasikan**: **Python 3.11** atau **Python 3.12**. Versi ini memiliki kestabilan tinggi, performa runtime yang jauh lebih cepat berkat optimalisasi *Specializing Adaptive Interpreter*, serta kompatibilitas 100% dengan NumPy, Pandas, Scikit-learn, dan PyTorch.

## Langkah Instalasi

### 1. Sistem Operasi Windows
1. Kunjungi situs resmi Python: [https://www.python.org/downloads/](https://www.python.org/downloads/).
2. Unduh installer **Windows installer (64-bit)** untuk versi 3.11.x atau 3.12.x.
3. Jalankan file `.exe` hasil unduhan.
4. **PENTING**: Pada layar pertama instalasi, centang kotak opsi:
   - `[x] Add python.exe to PATH` (Wajib dicentang agar perintah `python` dapat dikenali di terminal mana pun).
   - `[x] Use admin privileges when installing py.exe`.
5. Klik **Install Now** dan tunggu hingga proses selesai.
6. Pada akhir dialog, jika muncul opsi *Disable path length limit*, klik tombol tersebut untuk mencegah kendala path panjang di Windows.

### 2. Sistem Operasi macOS
1. Unduh installer resmi macOS dari situs Python.org, atau gunakan Homebrew via Terminal:
```bash
brew install python@3.12
```
2. Pastikan shell configuration (`~/.zshrc` atau `~/.bash_profile`) mengarahkan path ke binary Python yang baru dipasang.

### 3. Sistem Operasi Linux (Ubuntu / Debian)
1. Buka Terminal dan jalankan pembaruan paket:
```bash
sudo apt update
sudo apt install -y python3 python3-pip python3-venv
```

## Perintah Verifikasi & Membaca Output

Buka jendela terminal baru (PowerShell untuk Windows, atau Terminal untuk macOS/Linux). Jangan gunakan jendela terminal yang sudah terbuka sebelum instalasi selesai.

Jalankan perintah berikut:

```bash
python --version
```
*Interpretasi Hasil:*
Output harus menunjukkan versi Python yang Anda pasang, misalnya:
`Python 3.12.10` atau `Python 3.11.9`.
Jika muncul versi Python 2.x atau error *command not found*, periksa PATH sistem Anda.

Jalankan verifikasi `pip` (package installer):
```bash
python -m pip --version
```
*Interpretasi Hasil:*
Output menunjukkan versi pip dan direktori lokasi paket, contohnya:
`pip 24.x from ... (python 3.12)`

Periksa lokasi fisik file eksekusi:
- **Windows**:
```powershell
where.exe python
```
- **macOS / Linux**:
```bash
which python3
```
Output ini mengonfirmasi letak interpreter yang sedang aktif.

## Checkpoint Keberhasilan

- [ ] Perintah `python --version` menghasilkan nomor versi `3.11.x` atau `3.12.x`.
- [ ] Perintah `python -m pip --version` berjalan sukses tanpa error.
- [ ] Anda mengetahui path direktori instalasi Python di komputer Anda.

## Troubleshooting

- **Error: 'python' is not recognized as an internal or external command**
  *Penyebab:* Opsi `Add python.exe to PATH` tidak dicentang saat instalasi.
  *Solusi:* Jalankan kembali installer Python, pilih **Modify**, centang opsi PATH, lalu selesaikan wizard. Jangan lupa restart jendela terminal.
- **Kasus Windows App Execution Aliases:**
  *Gejala:* Mengetik `python` membuka Microsoft Store.
  *Solusi:* Buka *Settings* Windows → cari *Manage App Execution Aliases* → matikan (*Toggle OFF*) kedua alias bernama `python.exe` dan `python3.exe`.
