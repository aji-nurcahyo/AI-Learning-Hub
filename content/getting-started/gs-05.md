# GS-05: Jupyter Notebook, JupyterLab & Google Colab

Modul ini membahas cara kerja format Interactive Notebook (`.ipynb`), siklus hidup kernel, pengelolaan memori/state, serta panduan praktis menggunakan Google Colab secara bijak.

## Tujuan

Setelah menyelesaikan modul ini, Anda diharapkan mampu:
1. Menjelaskan hubungan antara editor notebook (UI) dan *kernel* (proses background eksekusi kode).
2. Memahami konsep *in-memory state* dan risiko bahaya *out-of-order cell execution*.
3. Menerapkan disiplin pengujian notebook dengan perintah *Restart Kernel and Run All Cells*.
4. Mengunggah dan mengunduh berkas pada lingkungan cloud Google Colab.
5. Menjelaskan sifat *ephemeral* (sementara) penyimpanan Colab dan batasan alokasi komputasi GPU gratis.

## Cara Kerja Notebook: UI vs Kernel

Sebuah notebook tidak mengeksekusi kode secara langsung di peramban web atau editor VS Code Anda:
- **Notebook Interface**: Dokumen interaktif yang menampilkan teks berformat Markdown dan blok kode Python dalam sel-sel terpisah.
- **Kernel**: Proses latar belakang independen yang menjalankan kode Python dan menyimpan seluruh variabel serta fungsi di memori RAM komputer.
- Ketika Anda menjalankan sebuah sel, kode dikirim ke kernel, dihitung, lalu hasilnya dikembalikan ke tampilan notebook bersama nomor urut eksekusi `[1]`, `[2]`, dst.

## Bahaya "Hidden State" & Out-of-Order Execution

Salah satu kesalahan paling umum mahasiswa saat belajar AI:
1. Anda membuat sel 1: `x = 10`. Anda mengeksekusinya.
2. Anda membuat sel 2: `y = x + 5`. Anda mengeksekusinya (`y` bernilai 15).
3. Anda kembali ke sel 1 dan mengubahnya menjadi `x = 100`, **tetapi Anda lupa mengeksekusi ulang sel 2**.
4. Nilai `y` di memori kernel tetap 15, padahal di layar terlihat `x = 100`. Kode menjadi tidak konsisten!

> **Aturan Emas Reproduktibilitas AI:**
> Sebelum menyerahkan tugas atau mempublikasikan notebook, selalu jalankan menu:
> **Kernel → Restart & Run All Cells** (di VS Code / Jupyter) atau **Runtime → Restart session and run all** (di Colab).
> Jika notebook tidak dapat dieksekusi secara mulus dari sel teratas hingga terbawah tanpa error pada kernel bersih, maka analisis Anda belum valid!

## Bekerja dengan Google Colab

Jika Anda menggunakan Google Colab ([colab.research.google.com](https://colab.research.google.com/)):

### 1. Mengunggah & Mengunduh File
- Klik ikon folder (**Files**) pada bilah navigasi di sisi kiri layar Colab.
- Tarik (*drag-and-drop*) file dataset Anda (misal `dataset.csv`) ke panel tersebut.
- Atau gunakan kode Python bawaan Colab:
```python
from google.colab import files
uploaded = files.upload()
```
- Untuk mengunduh hasil model atau visualisasi grafik:
```python
files.download('hasil_grafik.png')
```

### 2. Memahami Sifat Runtime Sementara (*Ephemeral Disk*)
- Seluruh file yang Anda unggah ke direktori lokal Colab (`/content/`) akan **terhapus secara permanen** begitu sesi Anda terputus (*disconnected*), browser ditutup terlalu lama, atau runtime di-*recycle* oleh Google.
- Jika Anda ingin menyimpan file secara persisten di cloud, kaitkan dengan Google Drive:
```python
from google.colab import drive
drive.mount('/content/drive')
```

### 3. Ketersediaan GPU Bukan Jaminan Otomatis
- Pada tier gratis Google Colab, Anda dapat memilih hardware accelerator melalui menu: **Runtime → Change runtime type → T4 GPU**.
- **Namun perhatikan:** Alokasi GPU gratis bersifat dinamis dan dibatasi oleh kuota penggunaan (*quota usage limit*). Google Colab tidak menjamin ketersediaan GPU setiap saat. Jika kuota Anda habis, Anda akan dialihkan kembali ke runtime CPU biasa.

## Troubleshooting

- **Error: NameError: name 'data' is not defined (padahal kode ada di atas)**
  *Penyebab:* Anda belum mengeksekusi sel di atasnya setelah membuka kembali notebook, atau kernel baru saja ter-restart.
  *Solusi:* Eksekusi sel pendefinisian variabel terlebih dahulu dari baris atas.
- **Kernel Crash / Out of Memory (OOM)**
  *Penyebab:* Dataset atau array tensor terlalu besar melebihi kapasitas RAM.
  *Solusi:* Restart kernel, kurangi ukuran batch (*batch size*), atau gunakan subset data yang lebih ringkas.
