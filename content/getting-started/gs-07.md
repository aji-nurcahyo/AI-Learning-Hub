# GS-07: PyTorch, CPU/GPU & CUDA

Modul ini memberikan panduan instalasi pustaka Deep Learning **PyTorch**, menjelaskan arsitektur komputasi CPU versus GPU, membedakan komponen driver dan CUDA runtime, serta mendemonstrasikan cara memeriksa ketersediaan perangkat keras secara objektif.

## Tujuan

Setelah menyelesaikan modul ini, Anda diharapkan mampu:
1. Mengidentifikasi perintah instalasi PyTorch versi CPU sebagai fondasi belajar yang stabil dan bebas hambatan konfigurasi driver.
2. Membedakan secara konseptual antara Hardware Driver, CUDA Toolkit, dan paket wheel PyTorch.
3. Menggunakan selector resmi PyTorch untuk mendapatkan perintah instalasi yang sesuai dengan sistem operasi Anda.
4. Menulis kode Python untuk mendeteksi ketersediaan akselerasi GPU secara dinamis tanpa mengasumsikan tipe perangkat keras tertentu.

## Mengapa Memulai dari Versi CPU?

Ketika pertama kali belajar Deep Learning (mempelajari konsep Tensor, Operasi Gradien, Autograd, dan arsitektur Perceptron):
- **Paket CPU jauh lebih ringan**: Ukuran unduhan paket PyTorch CPU berkisar ~150–200 MB, sedangkan paket PyTorch dengan CUDA bundling mencapai ~2 hingga 3 GB.
- **Bebas Kompatibilitas Hardware**: Berjalan di semua jenis laptop atau PC (Intel, AMD, Apple Silicon) tanpa memerlukan kartu grafis diskrit NVIDIA.
- **Kode Tetap 100% Identik**: Logika pembuatan model, fungsi loss, dan optimizer di PyTorch sepenuhnya identik antara CPU dan GPU; perbedaannya hanya terletak pada pemindahan tensor ke memori perangkat (`.to(device)`).

## Memahami Tiga Lapisan Berbeda: Driver vs CUDA vs PyTorch

Banyak pembelajar merasa bingung ketika berhadapan dengan error CUDA. Penting untuk memahami tiga lapisan independen ini:

1. **NVIDIA GPU Driver (Tingkat Kernel OS)**:
   - Driver perangkat keras yang dipasang langsung ke sistem operasi untuk mengendalikan kartu grafis fisik. Driver ini menentukan *versi CUDA maksimum* yang didukung kartu grafis Anda.
2. **CUDA Toolkit / Runtime**:
   - Platform komputasi paralel dari NVIDIA yang memungkinkan instruksi matematika dieksekusi oleh ribuan core GPU secara serempak.
3. **Paket PyTorch Wheel**:
   - Ketika Anda memasang PyTorch via pip dengan opsi CUDA (misalnya CUDA 12.x), PyTorch sudah menyertakan salinan CUDA runtime dinamisnya sendiri di dalam paket. Anda tidak selalu perlu mengunduh installer CUDA Toolkit raksasa secara terpisah dari situs NVIDIA, asalkan GPU Driver sistem operasi Anda sudah mutakhir.

## Kode Verifikasi Device Agnostic

Untuk menulis kode AI yang portabel (dapat berjalan di laptop tanpa GPU dan otomatis beralih ke GPU saat dijalankan di server atau Google Colab), gunakan pola standar berikut:

```python
"""
verify_torch_device.py
Memeriksa instalasi PyTorch dan ketersediaan akselerasi perangkat keras.
"""

import sys
import torch

print("=== VERIFIKASI INSTALASI PYTORCH ===")
print(f"Python: {sys.version.split()[0]}")
print(f"PyTorch Version: {torch.__version__}")

# Deteksi ketersediaan CUDA (GPU NVIDIA)
cuda_available = torch.cuda.is_available()
print(f"CUDA Available: {cuda_available}")

if cuda_available:
    device_count = torch.cuda.device_count()
    device_name = torch.cuda.get_device_name(0)
    print(f"Jumlah GPU terdeteksi: {device_count}")
    print(f"Nama GPU: {device_name}")
    device = torch.device("cuda")
else:
    print("Akselerasi GPU tidak terdeteksi. Sistem menggunakan CPU standar.")
    device = torch.device("cpu")

print(f"Target Device: {device}")

# Uji pembuatan Tensor dasar pada perangkat terpilih
x = torch.tensor([1.0, 2.0, 3.0], device=device)
y = x * 2.0
print(f"Operasi Tensor Berhasil: {y.cpu().numpy()} pada {device}")
```

Jalankan skrip ini:
```bash
python verify_torch_device.py
```

## Troubleshooting

- **Error: "Torch not compiled with CUDA enabled" saat memanggil `.cuda()`**
  *Penyebab:* Anda memasang PyTorch varian CPU, atau kartu grafis Anda tidak memiliki arsitektur CUDA.
  *Solusi:* Selalu gunakan penentuan device dinamis `device = torch.device("cuda" if torch.cuda.is_available() else "cpu")`. Jangan memanggil `.cuda()` secara hardcoded.
- **Error pada Windows: "OSError: [WinError 126] The specified module could not be found"**
  *Penyebab:* Pustaka runtime Microsoft Visual C++ Redistributable belum terpasang di Windows Anda.
  *Solusi:* Unduh dan pasang *Visual C++ Redistributable 2015-2022* dari situs resmi Microsoft, lalu restart komputer Anda.
