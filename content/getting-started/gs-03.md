# GS-03: VS Code & Python Development

Modul ini memandu Anda mengonfigurasi Visual Studio Code (VS Code) sebagai *integrated development environment* (IDE) utama untuk menulis, menjalankan, dan melakukan debugging pada script Python.

## Tujuan

Setelah menyelesaikan modul ini, Anda diharapkan mampu:
1. Memasang dan mengonfigurasi ekstensi Python resmi di VS Code.
2. Membuka folder kerja (*workspace*) secara terstruktur agar referensi file relatif berfungsi normal.
3. Memilih interpreter Python yang tepat melalui Command Palette.
4. Menjalankan script Python secara benar melalui *Integrated Terminal*.
5. Mengidentifikasi dan memperbaiki kesalahan konfigurasi interpreter yang sering memicu `ModuleNotFoundError`.

## Prasyarat

- Telah menyelesaikan modul GS-02 (Python telah terpasang dan terverifikasi di sistem).
- Visual Studio Code telah terpasang di komputer Anda ([unduh di code.visualstudio.com](https://code.visualstudio.com/)).

## Langkah Konfigurasi

### 1. Memasang Ekstensi Python
1. Buka Visual Studio Code.
2. Klik ikon **Extensions** pada Activity Bar di sisi kiri (atau tekan shortcut `Ctrl+Shift+X` di Windows/Linux, `Cmd+Shift+X` di macOS).
3. Ketik `Python` di kotak pencarian.
4. Pilih ekstensi **Python** yang dirilis resmi oleh **Microsoft** (termasuk paket otomatis *Pylance* dan *Python Debugger*).
5. Klik **Install**.

### 2. Membuka Folder Proyek (Bukan Sekadar Buka File)
Prinsip fundamental dalam proyek AI adalah membuka direktori proyek secara menyeluruh (*Open Folder*):
1. Klik menu **File** → **Open Folder...** (atau `Ctrl+K Ctrl+O`).
2. Pilih direktori kerja proyek Anda, misalnya `D:\ai-projects\proyek-01`.
3. Mengapa ini penting? Jika Anda hanya membuka satu file lepas (*Open File*), VS Code tidak dapat menentukan *working directory*, sehingga pembacaan file dataset dengan path relatif (`pd.read_csv('data/sample.csv')`) akan gagal menemukan file!

### 3. Memilih Python Interpreter
Untuk memastikan VS Code mengeksekusi kode menggunakan instalasi Python yang Anda inginkan:
1. Tekan kombinasi tombol `Ctrl+Shift+P` (Windows/Linux) atau `Cmd+Shift+P` (macOS) untuk membuka **Command Palette**.
2. Ketik dan pilih: `Python: Select Interpreter`.
3. Pilih interpreter yang sesuai dengan versi yang Anda pasang (atau environment `.venv` jika sudah dibuat).
4. Status interpreter yang terpilih akan tampil di bilah status bawah (*status bar*) VS Code di pojok kanan bawah.

### 4. Membuat dan Menjalankan Script Python Pertama
1. Di panel *Explorer* (sisi kiri), klik tombol **New File** dan beri nama `halo_ai.py`.
2. Tulis baris kode sederhana berikut:

```python
import sys

print("Selamat datang di AI Learning Hub!")
print(f"Versi Python yang aktif: {sys.version.split()[0]}")
print(f"Path executable: {sys.executable}")
```

3. Jalankan script dengan salah satu cara berikut:
   - Klik tombol segitiga hijau (**Run Python File**) di pojok kanan atas editor.
   - Atau klik kanan pada area editor, lalu pilih **Run Python File in Terminal**.
4. VS Code akan membuka **Integrated Terminal** dan mengeksekusi perintah Python secara otomatis.

## Troubleshooting

- **Masalah: Script berjalan di PowerShell sistem tetapi modul tidak ditemukan di VS Code**
  *Penyebab:* VS Code memilih interpreter global bawaan yang berbeda dengan environment tempat modul Anda dipasang.
  *Solusi:* Tekan `Ctrl+Shift+P` → pilih `Python: Select Interpreter` → arahkan secara eksplisit ke interpreter yang benar.
- **Masalah: Integrated Terminal tidak menampilkan prompt yang diharapkan**
  *Solusi:* Anda dapat membuka terminal manual kapan saja dengan menu **Terminal** → **New Terminal** (atau shortcut ``Ctrl+` ``).
