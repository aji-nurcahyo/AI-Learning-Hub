# GS-01: Memilih Learning Environment

Modul ini memandu Anda memilih lingkungan kerja (*development environment*) yang tepat untuk mempelajari Artificial Intelligence, Machine Learning, dan Deep Learning.

## Tujuan

Setelah menyelesaikan modul ini, Anda diharapkan mampu:
1. Menjelaskan perbedaan mendasar antara *local development environment* dan lingkungan *cloud-hosted notebook* seperti Google Colab.
2. Memilih format kerja yang tepat antara Interactive Notebook (`.ipynb`) dan Python script (`.py`) berdasarkan kebutuhan tahap pembelajaran.
3. Menjelaskan mengapa CPU standar sudah memadai untuk sebagian besar materi dasar dan kapan GPU mulai dibutuhkan.

## Prasyarat

- Komputer (laptop atau desktop) dengan sistem operasi Windows, macOS, atau Linux modern.
- Koneksi internet untuk mengunduh perangkat lunak dan paket Python pendukung.
- Browser web modern (Chrome, Edge, Firefox, atau Safari).

## Perbandingan: Local Environment vs Google Colab

| Aspek | Local Environment (VS Code + Python) | Google Colab (Cloud Notebook) |
|---|---|---|
| **Penyimpanan Kode** | Tersimpan langsung di disk lokal komputer Anda | Tersimpan di Google Drive atau instance sementara |
| **Ketergantungan Internet** | Hanya butuh saat instalasi paket; eksekusi offline | Wajib koneksi internet stabil terus-menerus |
| **Akses Hardware** | Terbatas pada spesifikasi laptop/PC lokal | Akses gratis ke CPU dan GPU dasar (dengan batasan kuota) |
| **Siklus Hidup Lingkungan** | Persisten; paket dan file tidak hilang saat reboot | Sesi sementara (*ephemeral*); file lokal hilang saat runtime reset |
| **Debugging & Tooling** | Fitur debugger, linting, git, dan refactoring lengkap | Terbatas pada tampilan sel notebook |
| **Rekomendasi Tahapan** | Sangat disarankan untuk Level 1, 2, dan fondasi rekayasa software | Solusi cepat jika PC lokal sangat terbatas atau eksperimen awal |

## Kapan Memakai Notebook vs Python Script?

Dalam ekosistem AI, kita menggunakan dua format utama:

1. **Jupyter Notebook (`.ipynb`)**:
   - Cocok untuk eksplorasi data awal (*exploratory data analysis*), eksperimen visualisasi grafik, pembuatan prototipe cepat, dan modul tutorial bertahap.
   - Menyimpan visualisasi grafik dan output secara langsung di samping penjelasan naratif.
   - **Kelemahan**: State variabel dapat menjadi tidak konsisten jika sel dieksekusi secara acak (*out-of-order execution*).

2. **Python Script (`.py`)**:
   - Standar industri untuk rekayasa perangkat lunak, sistem produksi, modularisasi kode, automation pipeline, dan pengujian unit (*unit testing*).
   - Eksekusi selalu deterministik dari baris pertama hingga terakhir.
   - Mendukung integrasi dengan version control (Git) tanpa kekacauan metadata output JSON.

> **Rekomendasi Jalur Belajar:**
> Untuk tahap awal (Level 1 & 2), gunakan **VS Code lokal** dengan gabungan file `.py` untuk latihan logika dan `.ipynb` untuk visualisasi. Jangan terburu-buru bergantung pada cloud notebook untuk tugas-tugas dasar.

## Realitas Kebutuhan Komputasi: CPU Cukup untuk Materi Awal

Sebuah kesalahpahaman umum adalah "belajar AI harus memiliki laptop gaming dengan GPU mahal". Faktanya:
- **Level 1 (AI Foundations)**: Algoritma pencarian, logika berbasis aturan (*Rule-Based System*), dan kalkulasi metrik berjalan dalam hitungan milidetik di CPU standar mana pun.
- **Level 2 (Machine Learning)**: Algoritma Scikit-learn (seperti Linear Regression, Decision Tree, Logistic Regression, dan Random Forest pada dataset berukuran kecil hingga menengah) dioptimalkan secara efisien untuk CPU multi-core.
- **Level 3 (Deep Learning Dasar)**: Pembelajaran arsitektur dasar dapat disimulasikan pada CPU. Ketika melatih Neural Network yang lebih dalam atau model Computer Vision, GPU diskrit lokal atau GPU gratis di Google Colab baru memberikan akselerasi yang signifikan.

## Troubleshooting

- **Pertanyaan: Apakah saya bisa belajar jika komputer saya hanya memiliki RAM 4 GB?**
  *Jawaban:* Ya, untuk Level 1 dan 2, kebutuhan memori sangat minim (< 500 MB untuk script dasar). Jika Anda menghadapi dataset besar pada level berikutnya, Anda dapat memanfaatkan runtime Google Colab tanpa biaya tambahan.
- **Pertanyaan: Apakah saya harus membeli langganan berbayar untuk belajar AI?**
  *Jawaban:* Tidak. Seluruh perangkat lunak yang digunakan dalam kurikulum ini bersifat open-source (Python, VS Code, Scikit-learn, PyTorch) dan tidak ada prasyarat layanan berbayar.
