# GS-06: Scientific Python Setup

Modul ini memandu instalasi dan verifikasi empat pustaka inti (*core libraries*) yang membentuk fondasi data science dan Machine Learning di Python: NumPy, Pandas, Matplotlib, dan Scikit-learn.

## Tujuan

Setelah menyelesaikan modul ini, Anda diharapkan mampu:
1. Menjelaskan peran spesifik masing-masing pustaka dalam pipeline pengembangan AI.
2. Memasang paket-paket saintifik ke dalam virtual environment proyek Anda.
3. Menjalankan skrip *smoke test* untuk memverifikasi keberhasilan impor dan keselarasan versi.

## Peran Empat Pilar Scientific Python

Dalam siklus pengembangan sistem cerdas, setiap pustaka memegang spesialisasi tertentu:

```
[Sumber Data (CSV/SQL)] 
         │
         ▼
     [Pandas]  ───> Pembersihan data tabular, inspeksi missing values, feature selection
         │
         ▼
     [NumPy]   ───> Representasi array numerik multi-dimensi, vektorisasi matematika cepat
      ┌──┴───────────────────────┐
      ▼                          ▼
 [Matplotlib]             [Scikit-learn]
 Visualisasi grafik,      Pelatihan model ML, evaluasi metrik,
 distribusi fitur         pembagian train/test split
```

1. **NumPy (`numpy`)**:
   - Menyediakan tipe data array berkecepatan tinggi berbasis bahasa C (*ndarray*).
   - Menghitung operasi aljabar linier, manipulasi matriks, dan kalkulasi matematis tanpa lambatnya loop murni Python.
2. **Pandas (`pandas`)**:
   - Mengelola data terstruktur berbentuk tabel (*DataFrame*) mirip spreadsheet Excel atau tabel SQL.
   - Sangat efisien untuk membaca file CSV/Parquet, menangani data hilang (*missing values*), pengelompokan (*groupby*), dan rekayasa fitur (*feature engineering*).
3. **Matplotlib (`matplotlib`)**:
   - Pustaka visualisasi data untuk menghasilkan grafik 2D berkualitas publikasi (scatter plot, histogram kurva loss, grafik perbandingan).
4. **Scikit-learn (`scikit-learn`)**:
   - Pustaka standar emas untuk algoritma Machine Learning klasik (Regresi, Klasifikasi, Klastering, Reduksi Dimensi).
   - Menyediakan fungsi evaluasi metrik (Accuracy, Precision, Recall, Confusion Matrix) serta pipeline transformasi data.

## Skrip Verifikasi (Smoke Test)

Buat file baru bernama `smoke_test_scientific.py` di dalam folder proyek Anda:

```python
"""
smoke_test_scientific.py
Skrip pengujian integritas instalasi pustaka saintifik dasar.
"""

import sys

def run_smoke_test():
    print("=== SMOKE TEST: SCIENTIFIC PYTHON STACK ===")
    print(f"Python Runtime: {sys.version.split()[0]} ({sys.platform})")
    print("-" * 42)

    # 1. Uji NumPy
    try:
        import numpy as np
        arr = np.array([1.0, 2.0, 3.0])
        print(f"[OK] NumPy {np.__version__} - Dot product test: {np.dot(arr, arr)}")
    except ImportError as e:
        print(f"[FAIL] NumPy gagal diimpor: {e}")

    # 2. Uji Pandas
    try:
        import pandas as pd
        df = pd.DataFrame({"fitur": [10, 20], "label": [0, 1]})
        print(f"[OK] Pandas {pd.__version__} - DataFrame shape: {df.shape}")
    except ImportError as e:
        print(f"[FAIL] Pandas gagal diimpor: {e}")

    # 3. Uji Matplotlib
    try:
        import matplotlib
        import matplotlib.pyplot as plt
        print(f"[OK] Matplotlib {matplotlib.__version__} - Backend: {matplotlib.get_backend()}")
    except ImportError as e:
        print(f"[FAIL] Matplotlib gagal diimpor: {e}")

    # 4. Uji Scikit-learn
    try:
        import sklearn
        from sklearn.metrics import accuracy_score
        y_true = [0, 1, 1, 0]
        y_pred = [0, 1, 0, 0]
        acc = accuracy_score(y_true, y_pred)
        print(f"[OK] Scikit-learn {sklearn.__version__} - Accuracy test: {acc:.2f}")
    except ImportError as e:
        print(f"[FAIL] Scikit-learn gagal diimpor: {e}")

    print("-" * 42)
    print("Verifikasi selesai. Jika seluruh baris berstatus [OK], lingkungan Anda siap!")

if __name__ == "__main__":
    run_smoke_test()
```

Jalankan skrip tersebut melalui terminal:
```bash
python smoke_test_scientific.py
```

## Checkpoint Keberhasilan

- [ ] Seluruh keempat modul (`numpy`, `pandas`, `matplotlib`, `sklearn`) berhasil diimpor tanpa memicu `ImportError`.
- [ ] Output mencetak versi yang terpasang dan status `[OK]`.
- [ ] Tidak terjadi crash interpreter atau peringatan kompilasi binary yang hilang.

## Troubleshooting

- **Error: No module named 'sklearn'**
  *Catatan:* Nama paket saat instalasi dengan pip adalah `scikit-learn` (menggunakan tanda hubung), sedangkan nama modul saat diimpor dalam kode Python adalah `sklearn`. Pastikan Anda memasangnya dengan `python -m pip install scikit-learn`.
- **Peringatan: Matplotlib GUI Backend Warning di Linux / Server headless**
  *Penyebab:* Sistem tidak memiliki server display X11.
  *Solusi:* Pada skrip berbasis server, tambahkan baris `matplotlib.use('Agg')` sebelum mengimpor `pyplot` agar grafik disimpan langsung ke file gambar tanpa jendela GUI.
