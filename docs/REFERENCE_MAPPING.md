# Pemetaan referensi

Diverifikasi 4 November 2026 melalui halaman resmi. Ini pemetaan cakupan rencana oleh pengembang, bukan klaim kesetaraan jam atau penguasaan seluruh knowledge unit.

| CS2023 knowledge unit | Tema | Chapter yang direncanakan |
|---|---|---|
| AI-Introduction | Fundamental Issues | 01–03 |
| AI-Search | Search | 03–04, 10 |
| AI-KRR | Fundamental Knowledge Representation and Reasoning | 05–06 |
| AI-ML | Machine Learning | 11–24, 29–32, 35 |
| AI-SEP | Applications and Societal Impact | 09, 19–20, 29–30, 36, 39–40 |
| AI-LRR | Logical Representation and Reasoning | 05 |
| AI-Probability | Probabilistic Representation and Reasoning | 05–06, 35 |
| AI-Planning | Planning | 03–04, 34–35; Robotics track |
| AI-Agents | Agents and Cognitive Systems | 03, 34–35, 40 |
| AI-NLP | Natural Language Processing | 27–29, 32–34, 38 |
| AI-Robotics | Robotics | 35, 38; Robotics track |
| AI-Vision | Perception and Computer Vision | 24–26, 31, 38 |

Dasar matematika chapter 06 juga terkait MSF; Python/data chapter 07–08 merupakan fondasi pendukung. Deployment, RAG, model optimization, dan tool integration memperluas kurikulum dengan praktik sistem modern. Planning eksplisit (state, goal, operator dan evaluasi plan) perlu dibahas pada 03–04 dan 34–35. Robotics track belum merupakan cakupan robotics lengkap.
