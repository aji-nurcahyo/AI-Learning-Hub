# Panduan bahasa teknis

Penjelasan menggunakan Bahasa Indonesia yang alami. Pertahankan istilah Artificial Intelligence, Machine Learning, Deep Learning, Neural Network, dataset, feature, label, training, validation, testing, inference, classification, regression, clustering, overfitting, underfitting, loss function, optimizer, backpropagation, CNN, Transformer, fine-tuning, embedding, tokenization, prompt, RAG, AI Agent, dan model deployment.

Jelaskan istilah saat pertama muncul: “Validation set adalah bagian dataset yang digunakan untuk memilih konfigurasi model; test set disimpan untuk evaluasi akhir.” Gunakan bentuk dan kapitalisasi yang konsisten dalam satu chapter.

Baik: “Deep Learning menggunakan Neural Network untuk mempelajari pola dari dataset selama proses training.” Hindari terjemahan literal yang mengaburkan makna seperti “pemasangan model”. Bedakan validation dan testing, parameter dan hyperparameter, korelasi dan kausalitas, prediction dan keputusan.

Gunakan kalimat aktif, contoh konkret, serta simbol matematika yang didefinisikan. Judul chapter mengikuti metadata English; uraian, tugas, rubric dan notes berbahasa Indonesia. Label Coming Soon berarti belum tersedia, bukan sudah selesai.

Jangan menyebut hasil “terbukti”, “akurat”, atau “siap produksi” tanpa protokol, metrik, batasan, dan bukti. Hindari antropomorfisme yang menyesatkan tentang LLM. Nyatakan ketidakpastian dan konteks evaluasi.
