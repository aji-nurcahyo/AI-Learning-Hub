# Register lisensi

Ditinjau 4 November 2026. Register ini mencatat sumber dan batas penggunaan; bukan pemberian lisensi atas karya pihak lain.

| Sumber | Status / lisensi | Penggunaan dan tindakan |
|---|---|---|
| Kode referensi lokal | Diadaptasi atas instruksi pemilik; notice upstream MIT dipertahankan | Lihat THIRD_PARTY_NOTICES.md; identitas baru tidak menggantikan copyright asal |
| LICENSE.upstream | MIT; Hakim El Hattab dan kontributor Reveal.js | Disalin persis dan disertakan pada dist |
| Paket npm langsung dan transitif | Lisensi dari package.json terpasang dalam DEPENDENCY_LICENSES.json | Versi dikunci package-lock.json; notice paket tetap dipertahankan |
| Fontsource Google Sans Flex / Code, Material Symbols Rounded | Periksa lisensi paket dan file LICENSE yang disertakan pada dist/licenses | Jangan menghapus notice font |
| CS2023 Januari 2024 | Copyright ACM/IEEE/AAAI; penggunaan guidelines untuk pengembangan materi/program diizinkan; penggunaan lain memerlukan izin | Adaptasi struktur saja, tanpa menyalin buku/diagram. https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm |
| UNESCO 2024 | Hak dan lisensi publikasi harus ditinjau sebelum redistribusi | Hanya rujukan dan sintesis mandiri. https://www.unesco.org/en/articles/ai-competency-framework-students |
| NIST AI RMF 1.0 | Periksa notices pada artefak yang akan digunakan | Hanya rujukan. https://www.nist.gov/itl/ai-risk-management-framework |
| Google MLCC | Teks/kode memiliki ketentuan masing-masing; jangan menganggap seluruh media berlisensi sama | Hanya rujukan. https://developers.google.com/machine-learning/crash-course/ |
| Dataset dan model | Tidak disertakan | Wajib catat URL, versi, checksum, lisensi, atribusi, batas penggunaan dan data personal sebelum publikasi |
| Contoh Python/library ML | Belum disertakan sebagai pembelajaran | Verifikasi API, versi, installation, CPU/GPU dan lisensi pada tahap penulisan |

Tidak memberi lisensi blanket pada seluruh codebase atau materi baru. Pemilik dapat menentukan lisensi untuk kontribusi original secara terpisah tanpa mengubah notice pihak ketiga.
